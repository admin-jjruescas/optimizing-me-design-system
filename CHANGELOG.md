# Changelog — Optimizing Me Design System

All notable design decisions, dated, with the reason why. Newest first.

## v1.0 — 2026-07-14

Initial release.

- **Tokens:** full CSS token set (`styles.css` + `tokens/`) — brand palette with navy/orange/periwinkle/peach scales, semantic aliases, dark-theme scope, 4px spacing grid, Montserrat + TT Phobos type scale, effects/motion.
- **Components:** brand (Logo, Eyebrow, PillarCard), core (Button, IconButton, Badge, Tag, Card, Stat, Testimonial), forms, navigation (Tabs, Accordion), feedback (Dialog, Toast, Avatar), marketing (PricingCard), curated outline Icon set.
- **Templates:** landing page, IG carousel (EN + ES), talk deck.
- **UI kits:** website, IGNITE, 7-Day Challenge, O2 Reset Barcelona, HumanOS, Resetea Bolivia.
- **Docs:** readme.md (rules + manifest), tokens.md (human-readable token reference), SKILL.md (agent entry).
- **Known caveat:** TT Phobos binaries are trial-license — replace with licensed files before commercial production.
