**Card** — rounded surface with soft shadow. The base container for content blocks.

```jsx
<Card tone="light" interactive>…</Card>
<Card tone="dark">…</Card>
<Card accent="var(--accent)">…</Card>
```

- Tones: `light` (white, default), `soft` (peach), `dark` (navy).
- `interactive` adds a calm hover lift. `accent` adds a colored top-border.
